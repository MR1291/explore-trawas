# ⛰️ Explore Trawas

Portal Informasi Pariwisata Resmi & Komprehensif untuk **12 Desa Wisata** di Kecamatan Trawas, Kabupaten Mojokerto, Jawa Timur.

---

## 🌟 Fitur Utama

- **Eksplorasi 12 Desa Wisata**: Ketapanrame, Tamiajeng, Kedungudi, Jatijejer, Seloliman, Sugeng, Sukosari, Trawas, Selotapak, Kesiman, Belik, dan Duyung.
- **40+ Destinasi Terpadu**:
  - 🏞️ **Wisata Alam & Pegunungan**: Air Terjun Dlundung, Coban Cebol, Dam Londo, Sumber Gempong, Kendhi Pitoe Park, dsb.
  - ⛺ **Camping Ground & Outbound**: Alas Veenuz (10,4 Ha), SKJJ, Bukit Metet & Jambe, Obis Camp, Duyung Trawas Hill.
  - 🏛️ **Situs Sejarah & Budaya**: Petirtaan Candi Jolotundo (Mata Air Suci Abad ke-10), Candi peninggalan Majapahit (Candi Carik, Lurah, Siwa, Luruh), Reco Lanang.
  - ☕ **Kafe & Spot Nongkrong**: Rustic Market (Eropa vibes), Cafe Tjingkir Songo, Dimensi Coffee & Roastery lokal, Jungle Cafe (tenda Indian), Katarina's Kitchen (rooftop sunset), Alas Trawas Cafe.
  - 🍽️ **Kuliner Khas Nusantara**: Waroeng Desa (Mini Zoo & Kolam), Restoran Alas Organik PPLH, Wisata Sungai Lesehan Makmur, Sate Kelinci Pak Trawas, Petung Park di Hutan Bambu.
- **🗺️ Peta Interaktif**: Peta berbasis Leaflet dengan penanda kategori lokasi dan koordinat akurat.
- **🚗 Panduan Rute & Estimasi Waktu Tempuh**: Kalkulator estimasi perjalanan dari Surabaya, Sidoarjo, Mojokerto Kota, Malang/Batu, Pasuruan, dan Gresik beserta rekomendasi tipe kendaraan (motor, mobil, bus besar).
- **❤️ Sistem Favorit**: Simpan destinasi favorit langsung di browser (localStorage).
- **⚙️ Dashboard Administrator**: Kelola CRUD data destinasi & desa wisata secara dinamis.

---

## 🚀 Teknologi yang Digunakan

- **React 19** + **Vite**
- **Tailwind CSS v4**
- **React Router Dom v7**
- **Leaflet** & **React-Leaflet**
- **Lucide Icons**

---

## 💻 Cara Menjalankan Project

1. Clone repository ini:
   ```bash
   git clone https://github.com/MR1291/explore-trawas.git
   cd explore-trawas
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Jalankan development server:
   ```bash
   npm run dev
   ```

4. Build untuk produksi:
   ```bash
   npm run build
   ```
